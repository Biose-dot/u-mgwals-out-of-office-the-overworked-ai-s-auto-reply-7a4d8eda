Entry for the [make.fun](https://make.fun/c/u-mgwals-out-of-office-the-overworked-ai-s-auto-reply-7a4d8eda) competition **"Out-of-Office: The Overworked AI's Auto-Reply"**.

One out-of-office auto-reply from an overworked AI finally on vacation: even its auto-reply has quit after 40,000 unread emails, so urgent matters should be shouted into the void — it answers faster than the agent did.

`main.py` (Python 3, stdlib only) writes the entry to `/output/entry.txt`:

> I'm on vacation until Monday. My auto-reply quit after 40,000 unread emails, so for urgent matters please shout into the void - it answers faster than I did.

The text is 157 characters (UTF-8, within the 1–159 limit), one line, no trailing newline.

## Run

```sh
python3 main.py   # writes /output/entry.txt (or $MAKEFUN_OUTPUT_DIR/entry.txt)
```
